# 🐾 Project Poofs — Your AI-Powered Virtual Pet Extension

Say hello to **Project Poofs** — a Chrome extension that brings adorable, AI-powered virtual pets to your screen.  
Drag them around, chat with them, unlock new ones through mystery boxes, and enjoy some company while you surf the web.

Inspired by the blind box craze and our collective need for wholesome distractions.

---

## ✨ Features

- 🧸 **Draggable Virtual Pets**  
  Poofs live on your screen and follow you around your browser. Drag them. Boop them. Name them if you must.

- 🎁 **Blind Box Unlock System**  
  Collect new Poofs by opening randomized blind boxes. The more you explore, the weirder (and cuter) they get.

- 💬 **Chat with Your Poof**  
  Each pet has a voice! Powered by the **ChatGPT API**, Poofs respond to your messages in real-time.

- 🔐 **Firebase-Powered Accounts**  
  Log in and save your progress. Your pets, your convos, your box history — safely stored in **Firestore**.

- 🎨 **Clean, Delightful UI**  
  Built using **React**, **Tailwind CSS**, and **shadcn/ui** to create a polished, playful experience.

## 🛠 Tech Stack

| Tech           | Role                            |
|----------------|---------------------------------|
| Vite           | Lightning-fast build tool       |

| Tailwind CSS   | Utility-first styling           |
| shadcn/ui      | UI components with aesthetic    |
| Firebase       | Auth & Realtime DB (Firestore)  |
| ChatGPT API    | AI chat engine for Poofs        |
| React Router   | Page navigation & structure     |
